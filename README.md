# 观色 · 中国色彩工作台

一个无构建依赖、可静态部署的中国色彩工作台。界面、配色模板和交互重新设计，色库已恢复为原有 320 张色卡，保留原有编号、HEX，以及「将校呢」棕调与深调的区分。

## 本地查看（无需服务）

直接双击仓库根目录的 `index.html`，即可在浏览器打开。

这是自包含版本，色库、样式和脚本都已内嵌，不需要登录、联网或启动本地服务。也可以打开 `dist/index.html`；使用这个入口时须保留同目录中的 `colors.js`、`extract-examples.js`、`app.js` 与 `styles.css`。

收藏按浏览器和文件地址保存。之前通过 localhost 保存的收藏不会自动出现在 file 页面，可用收藏备份导入迁移。

可选开发预览：`python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`。

## 功能

- 320 色、10 色系、中文 / HEX 搜索、色相 / 明度 / 名称排序、两种网格密度、滚动接近底部时自动分批加载（无需点击）。
- 色彩详情、HEX / RGB / HSL 复制、相近颜色、随机探索。
- 36 组原创配色灵感，按四时 / 山野 / 器物 / 建筑分类。
- 2–8 色工作台：草稿、锁定、四种生成规则、撤销、调整顺序、自定义 HEX 与色盘编辑、实时设计预览。
- PNG、SVG、CSS、JSON 导出。
- 图片主色提取（缩图采样 + K-means 聚类）、近似传统色匹配；图片不上传。
- WCAG 文字对比度计算、前景背景交换、AA / AAA 提示。
- 浏览器本地收藏、命名配色、JSON 收藏备份与合并导入。
- 明暗主题（页面右上角）、响应式布局、键盘焦点、原生模态框、减少动态偏好。

## 文件

- `dist/index.html`：应用入口。
- `dist/styles.css`：响应式样式。
- `dist/app.js`：全部交互和本地算法。
- `dist/colors.json`：可维护的色库数据。

## 数据边界

无服务器账户和云同步。收藏使用 localStorage，只在当前浏览器保存；其他设备使用备份导入。传统色不是标准化的唯一色值，供数字设计参考。图片取色占比为采样近似，最近色以 RGB 距离衡量。配色生成基于规则和精选模板。



## 更新本地单文件

修改 `dist/` 后运行 `python3 scripts/build-local.py`，即可更新浏览器数据脚本以及仓库根目录的 `index.html`。该脚本不联网、不发布。
